# Quick Modules for Divi

**Your favorite modules. Your workflow, supercharged.**

Quick Modules for Divi is a lightweight, completely free plugin for **Divi 5** that adds your **favorite modules** and **recently used modules** directly to the top of the module picker for faster access.

It works in both the **Divi Visual Builder** and **Theme Builder**, helping you spend less time searching through long module lists and more time building.

---

## ✨ Features

- ⭐ **Favorite Modules**  
  Mark the Divi modules you use most and keep them at the top of the module picker.

- 🕘 **Recently Used Modules**  
  Automatically keeps track of your recently inserted modules.

- ↕️ **Drag & Drop Favorites**  
  Reorder your favorite modules however you like.

- ⚡ **Quick Module Insertion**  
  Insert modules directly from Favorites or Recent.

- 🌙 **Dark Mode Support**  
  Designed to integrate naturally with Divi's dark interface.

- ☀️ **Light Mode Support**  
  Fully adapted for Divi's light interface with proper contrast and styling.

- 🧩 **Visual Builder Support**  
  Works directly inside the standard Divi 5 Visual Builder.

- 🏗️ **Theme Builder Support**  
  Also works when editing headers, footers and templates in the Divi Theme Builder.

- 👤 **Per-user Preferences**  
  Favorites and recent modules are stored separately for each WordPress user.

- 🪶 **Lightweight**  
  No unnecessary database tables and no assets loaded on the public frontend.

- 🔒 **Privacy Friendly**  
  No tracking, telemetry or external services.

---

## 🎯 Why Quick Modules for Divi?

Divi 5 makes it possible to work with a growing collection of native and third-party modules.

But when you repeatedly use the same modules, searching through the entire module picker every time can slow down your workflow.

Quick Modules for Divi keeps the modules you actually use right where you need them.

**Favorites. Recent. Faster.**

---

## 🖱️ How It Works

### Favorites

Click the star next to any Divi module to add it to your Favorites.

Your favorite modules appear at the top of the module picker and can be reordered using drag and drop.

Click the star again to remove a module from Favorites.

### Recent Modules

Whenever you insert a module, Quick Modules automatically adds it to your Recent list.

Recently used modules are ordered automatically, with the most recently used module appearing first.

### Quick Insert

Click a module inside Favorites or Recent to insert it directly into your layout.

## 📦 Installation

1. Download the latest release.
2. Go to **WordPress → Plugins → Add New Plugin**.
3. Click **Upload Plugin**.
4. Upload the Quick Modules for Divi ZIP file.
5. Activate the plugin.
6. Open the Divi 5 Visual Builder or Theme Builder.
7. Click **Add Module** and start adding favorites.

No configuration page is required.

---

## ✅ Requirements

- WordPress 6.5 or newer
- PHP 7.4 or newer
- Divi 5

Quick Modules for Divi is specifically designed for the Divi 5 builder architecture.

---

## 🚀 Performance

Quick Modules for Divi is designed around a simple principle:

> Add convenience to the builder without adding weight to the website.

The plugin:

- Does not create custom database tables.
- Does not load CSS or JavaScript on the public frontend.
- Stores preferences using WordPress user metadata.
- Loads its interface only when needed inside Divi.
- Does not make requests to third-party services.

---

## 🔐 Privacy

Quick Modules for Divi:

- Does not collect personal data.
- Does not include analytics.
- Does not include telemetry.
- Does not track builder activity.
- Does not communicate with external servers.

Favorites and recent-module preferences remain inside your WordPress installation.
